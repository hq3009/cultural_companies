# 文旅企业信用白名单：正面指标与负面指标

用途：为文旅企业信用白名单评选挑指标。依据 `docs/fields.md`（标准表字段名汇总）与 `docs/数据库字段与结构/金融主题库字段表_20250715.xlsx`，状态编码参照 `docs/企业状态码值.xlsx`。标注只写你有权限读取的 `odps_jrsjc_pod.dw_*` 标准表，不写贴源层表，不引用 `INDEX_*`、`DESEN_INDEX_*` 指标表；字段表的“指标”页只用来理解指标口径。企业范围以 `src/culture_2026.sql` 按 `industry_codes` 的 63 个四位行业代码筛出的主体为界。

**口径约定**：正面指标是数值越高或次数越多越好的加分项，用于通过准入后的排序择优；负面指标是命中即扣分或否决的风险项。白名单是信用名单，宜“负面先行”，即严重负面作一票否决，一般负面作扣分，正面指标只在通过否决后参与排序。指标页中的近 1 年次数、占比、环比一类派生值，需在标准表上按说明列的时间字段自行聚合；“2、个人”部分（法人年龄、个人公积金等）对象是人，不纳入企业白名单。

## 三、落到评选口径时的要点

1. 顺序建议：先用负面第 1 组作否决，再用第 2、3 组扣分，最后用正面指标排序。现有 `SECTION 8` 的否决项只有 `xzcf_count`、`yzwf_count`、`jyyc_count`、`sxr_count`，排序只有 `asset_zmt` 与 `pens_num`，另有 `nb_year = 2025` 的数据门槛；可补主体状态、税务黑名单、非正常户、未履行生效裁判、欠税进否决，补纳税信用 A 级、公共信用分、社保公积金连续性进排序。
2. 时效要先核对：台账记录 `dw_nb_sw_xypjxxa` 止于 2021 年，`dw_nb_dsj_xypjxx` 评价时间样例为 2022 年，`dw_nb_scjdgl_qynbzcxx` 为 2013 至 2019 年且不更新，行政处罚公示止于 2021 年。用过期评价结果评当年白名单会失真。
3. 关联键以 `uni_social_crd_cd` 为主。`dw_nb_sw_qsxx`、`dw_nb_sw_zdsswfhmd` 用 `tax_no` 或纳税人名称，`dw_nb_kj_sgczkjxzxqy` 只有 `comp_nm`，这些表须先做标识映射，不宜按名称直接判定否决。
4. `dw_nb_scjdgl_qyzxxx`（企业注销）、`dw_shl_sgsxzcf`（双公示处罚）等虽有标准表名，但 `fields.md` 标注为“没有对应表”，不要写进可计算指标；主体资格改用 `reg_state` 判断。
